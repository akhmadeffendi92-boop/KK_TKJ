Modul 1: Dasar Hardware Jaringan

Mengidentifikasi Perangkat Jaringan Komputer

Memahami secara menyeluruh klasifikasi, karakteristik teknis, fungsi spesifik, dan port arsitektur dari setiap perangkat jaringan aktif dan pasif yang digunakan dalam infrastruktur modern.

Pengertian Perangkat Jaringan

Perangkat Jaringan Komputer adalah seluruh komponen keras (hardware) yang saling terhubung untuk memfasilitasi komunikasi data, berbagi sumber daya (resource sharing), transmisi paket data, serta keamanan lalu lintas data antar entitas komputasi. Dalam praktiknya, perangkat dibagi menjadi dua kategori utama:

Perangkat Aktif (Active Hardware)

Perangkat yang membutuhkan daya listrik untuk mengolah, mentransformasikan, mengarahkan, dan memperkuat sinyal data digital. Contoh: Router, Switch, Access Point, Firewall Hardware, ONT/Modem.

Perangkat Pasif (Passive Hardware)

Perangkat penyalur/media perantara yang tidak membutuhkan energi listrik untuk memproses bit data secara logis. Contoh: Kabel UTP/STP, Fiber Optic, Patch Panel, Connector RJ-45, Modular Jack, Server Rack.

Katalog & Identifikasi Perangkat Jaringan

OSI Layer 3 (Network)

1. Router

Perangkat penghubung antar segmen IP subnet yang berbeda.

Fungsi Utama: Menentukan jalur data terbaik (routing), melakukan Network Address Translation (NAT), DHCP Server, dan Firewall Filtering.
Jenis Umum:
  • MikroTik RouterBOARD (RB750Gr3, RB1100AHx4)
  • Cisco ISR Series (2911, 4331)
  • Wireless Home Router (TP-Link, D-Link)
Tipe Port: Ethernet (RJ-45), SFP/SFP+ Optical, Console Port (RJ-45/DB9).
OSI Layer 2 / Layer 3

2. Switch Ethernet

Konsentrator transmisi frame data berdasarkan MAC Address.

Fungsi Utama: Menghubungkan banyak perangkat lokal (LAN) tanpa tumbukan paket (collision domain terisolasi per port).
Kategori:
  • Unmanaged: Plug-and-play, tanpa konfigurasi.
  • Managed Layer 2: Mendukung VLAN, Spanning Tree (STP), Port Security.
  • Layer 3 Switch: Mendukung routing inter-VLAN internal kecepatan tinggi.
  • PoE Switch: Menyalurkan listrik & data via kabel LAN (IEEE 802.3af/at).
OSI Layer 1 & 2

3. Access Point (Wireless)

Memancarkan gelombang radio (RF) untuk koneksi nirkabel.

Fungsi Utama: Mengubah sinyal kabel LAN (Ethernet) menjadi sinyal frekuensi radio (2.4 GHz & 5 GHz / 6 GHz).
Standar Wi-Fi: Wi-Fi 4 (802.11n), Wi-Fi 5 (802.11ac), Wi-Fi 6 (802.11ax).
Model Operasi:
  • Standalone: Konfigurasi mandiri satu per satu.
  • Controller Managed: Dikelola terpusat (Aruba, UniFi Controller, Ruijie Reyee).
OSI Layer 3 - Layer 7

4. Firewall Hardware / UTM

Perangkat garda depan keamanan perimeter jaringan.

Fungsi Utama: Deep Packet Inspection (DPI), Antivirus Gateway, Intrusion Prevention System (IPS), Web Filtering, VPN Concentrator.
Vendor Populer: Fortinet FortiGate, Palo Alto Networks, Sophos XGS, Cisco Firepower.
OSI Layer 1 & 2

5. ONT / ONU Modem

Perangkat terminating jaringan Fiber to the Home (FTTH).

Fungsi Utama: Konversi sinyal cahaya (optical signal) dari jaringan GPON/EPON ISP menjadi sinyal elektrik Ethernet/Wi-Fi.
Interface: Port SC/UPC Fiber Optic, Port RJ-45 LAN, Port Telp (RJ-11).
OSI Layer 1

6. Media Converter & SFP

Penyambung antar jenis transmisi media fisik berbeda.

Fungsi Utama: Memperjauh jarak transmisi LAN melebihi batas 100 meter kabel tembaga dengan mengonversinya ke Fiber Optic.
Komponen: Transceiver SFP (Small Form-factor Pluggable) 1Gbps / SFP+ 10Gbps.

Modul 2: Perencanaan & Sizing

Memilih Perangkat Sesuai Kebutuhan Pengguna

Metodologi analisis teknis berdasarkan kepadatan pengguna, kebutuhan throughput, standar keamanan, ketersediaan anggaran, dan reliabilitas jaringan.

1

User Density & Kepadatan Port

Hitung jumlah end-device aktif (PC, AP, IP Camera, Printer). Tambahkan margin ekspansi 20-30%. Menentukan apakah membutuhkan switch 8, 16, 24, atau 48 port.

2

Throughput & Bandwidth

Bedakan jaringan kelas Fast Ethernet (100Mbps) untuk transaksi teks biasa dengan Gigabit (1000Mbps) atau 10G untuk transfer file besar, video streaming, & server backup.

3

Power over Ethernet (PoE)

Memeriksa apakah perangkat seperti Access Point dan IP Cam membutuhkan daya via LAN. Hitung Total PoE Budget (Watt) perangkat penerima (IEEE 802.3af/at/bt).

Modul 3: Implementasi Kontekstual

5 Skenario Relevan Perencanaan Jaringan

Skenario lapangan konkret untuk membantu peserta didik membayangkan penerapan nyata pemilihan hardware dalam berbagai lingkungan kerja.

Skenario 1

Warnet eSport & Cyber Cafe Modern (30 PC High-End)

Kondisi: Pemilik usaha membutuhkan latency sangat rendah (ping kecil & stabil), zero packet loss, bandwidth internet 200 Mbps Dedicated, dan isolasi jaringan antara PC Client game dengan lalu lintas Wi-Fi pengunjung cafe.

Rekomendasi Perangkat: Router MikroTik CCR1009 / RB1100AHx4 (Manajemen Queue PCQ & Dual WAN ISP).
Switching: Switch Gigabit Managed L2 36/48 Port (Full Cat6 UTP cabling ke setiap desk PC).
Wireless: Access Point Dual-Band terpisah di VLAN Guest khusus pengunjung cafe.
Skenario 2

Lab Komputer Sekolah SMK TKJ (40 PC Client + Server Local)

Kondisi: Digunakan untuk Ujian Berbasis Komputer (CBT), praktikum networking, transfer file ISO sistem operasi antar client dan server local secara masif.

Rekomendasi Perangkat: Switch Managed Gigabit 48-Port dengan Port Uplink SFP 10G ke Server Lokal.
Fitur Wajib Switch: Support VLAN ID, Port Security (membatasi MAC Address), dan Spanning Tree Protocol (STP) untuk mencegah loop akibat siswa salah colok kabel.
Router Gateway: MikroTik RB750Gr3 / RB3011 untuk pemblokiran situs non-edukatif & NAT.
Skenario 3

Perkantoran 3 Lantai (150 Karyawan + VoIP Phone + IP Cam)

Kondisi: Setiap lantai diisi divisi berbeda (HRD, Keuangan, IT, Sales). Butuh pemisahan keamanan antar divisi, telepon IP (VoIP), 16 unit IP Camera CCTV, dan access point Wi-Fi di seluruh area.

Lantai 1 (Ruang Server): Core L3 Switch Stackable & Hardware Firewall FortiGate 60F / 80F.
Lantai 2 & 3: Distribution / Access Switch 24-Port PoE+ (IEEE 802.3at) untuk mensuplai daya ke IP Phone & Ceiling Access Point tanpa perlu adaptor daya terpisah.
Media Antar Lantai: Patch Cord Fiber Optic Multimode OM3 terhubung via modul SFP+.
Skenario 4

Coworking Space & Outdoor Garden Cafe (100+ Wireless Client)

Kondisi: Mayoritas pelanggan menggunakan laptop & smartphone nirkabel. Area outdoor terkena hujan ringan dan terik matahari, butuh fitur Captive Portal (login voucher jam-jaman).

Outdoor Wi-Fi: Access Point Outdoor Weatherproof IP67 (e.g., Ruijie Reyee RG-RAP6260 / TP-Link EAP225-Outdoor).
Management: Cloud-managed Wi-Fi Controller untuk memantau trafik client dan Seamless Roaming tanpa terputus saat berpindah tempat.
Skenario 5

Koneksi Antar Gedung Cabang Jarak 3 Km (Point-to-Point Wireless)

Kondisi: Menghubungkan Kantor Pusat dengan Gedung Gudang berjarak 3 Km tanpa jalur galian fisik kabel fiber optik di jalan raya publik.

Rekomendasi Perangkat: Sepasang Antena Wireless Outdoor Point-to-Point (PtP) High Gain Dish 5 GHz (e.g. Ubiquiti PowerBeam 5AC / Mikrotik Wireless Wire Dish).
Syarat Teknis: Line of Sight (LOS) sempurna tanpa halangan pohon atau gedung tinggi di daerah Fresnel Zone.
Modul 4: Problem Solving & Trouble Analysis

5 Studi Kasus Evaluasi & Rekayasa Jaringan

Analisis kegagalan/masalah nyata di lapangan, identifikasi akar penyebab (*root cause*), dan penetapan solusi pemilihan perangkat replacement yang tepat.

1 Kasus: Wi-Fi Restoran Sering "Connected No Internet" & Broadcast Storm
Permasalahan (Problem)

Restoran menggunakan 1 unit Wireless Router rumahan standar untuk 80 pengunjung bersamaan. Wi-Fi sering hang, IP Address habis (DHCP Subnet /24 penuh), dan pengunjung saling mengintersepsi lalu lintas data.

Analisis Kebutuhan

Sifat Wireless Router rumahan tidak didesain menampung concurrency user melebihi 15-20 device. Tidak ada isolasi client (AP Isolation), CPU Router *overload* 100%, serta alokasi pool IP terlalu sempit.

Solusi Perangkat Optimal

Ganti ke MikroTik RB4011 (Dedicated Router & DHCP Subnet /22 = 1000 IP) + 2-3 Unit Ceiling Enterprise Access Point Dual-Band Wi-Fi 6 (support Beamforming, MU-MIMO, Client Isolation).

2 Kasus: Transfer File Lambat & High Latency di Lab Komputer SMK
Permasalahan (Problem)

Saat 40 PC siswa mendownload file gambar kerja sebesar 2GB dari server lokal bersamaan, transfer rate drop hingga 1 MB/s dan pingsan paket data tinggi.

Analisis Kebutuhan

Ditemukan switch yang dipakai masih kelas Fast Ethernet (10/100 Mbps) dengan kabel Cat5 tua. Port Uplink ke server menjadi *bottleneck* parah karena hanya bernilai max 100Mbps dibagi 40 PC.

Solusi Perangkat Optimal

Re-cabling ke Kabel UTP Cat6 Gigabit + Ganti switch ke Managed Gigabit Switch 48-Port dengan Dual SFP+ Uplink 10Gbps langsung menuju LAN Card Server.

3 Kasus: Kebocoran Data & Konflik IP antar Divisi Keuangan dan Tamu Kantor
Permasalahan (Problem)

Tamu kantor yang menyambung Wi-Fi bisa melihat folder *shared* berisi slip gaji di PC Keuangan, dan sering terjadi IP Address Conflict yang mematikan koneksi PC Direktur.

Analisis Kebutuhan

Topologi jaringan bersifat **Flat Network** (semua perangkat dalam 1 IP Broadcast Subnet yang sama, menggunakan unmanaged switch biasa).

Solusi Perangkat Optimal

Menerapkan Managed L2/L3 Switch dengan Segmentasi VLAN (VLAN 10: Keuangan, VLAN 20: Staff, VLAN 30: Guest Wi-Fi) + Dibuatkan Inter-VLAN Firewall ACL di Router untuk memblokir akses Guest ke VLAN Keuangan.

4 Kasus: Kamera IP CCTV Sering Offline di Gudang Luar Area (Jarak 150m)
Permasalahan (Problem)

Pemasangan IP Cam CCTV di pos satpam gudang dengan kabel UTP Cat5e sepanjang 150 meter dari switch utama sering putus-putus dan gambar patah-patah.

Analisis Kebutuhan

Melanggar batas maksimum teori & fisik transmisi data kabel UTP Tembaga (maksimal 100 Meter). Sinyal mengalami redaman (*attenuation*) parah.

Solusi Perangkat Optimal

Menggunakan Kabel Fiber Optic Single-Mode 2 Core + Sepasang Media Converter Fiber to Ethernet (atau Switch PoE lokal yang dihubungkan via modul SFP Optical).

5 Kasus: Internet Kantor Total Lumpuh Saat Kabel FO Indihome Putus
Permasalahan (Problem)

Perusahaan fintech mengalami kerugian besar saat kabel serat optik penyedia layanan internet utama terputus oleh galian jalan. Seluruh transaksi mati selama 6 jam.

Analisis Kebutuhan

Ketiadaan sistem redundansi (*Single Point of Failure*) pada tautan WAN Internet dan ketidakmampuan router eksisting mengelola lebih dari 1 jalur ISP.

Solusi Perangkat Optimal

Implementasi Dual WAN Load Balancing & Failover Router (MikroTik / FortiGate) dengan melanggan 2 ISP berbeda (ISP A: Fiber Optic Dedicated, ISP B: Wireless Broadband/GSM Backup).
